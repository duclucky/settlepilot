# Checklist nộp bài Tameion

Đây là checklist trung lập, không gắn với ý tưởng hay RFB nào.

## Bắt buộc

- [ ] Gửi [form nộp bài chính thức](https://forms.gle/BBWrdfuircrKiG2i6) trước hạn.
- [ ] GitHub repository công khai.
- [ ] Video walkthrough Loom, YouTube hoặc Vimeo, tối đa 3 phút.
- [ ] Problem statement, project description và traction trung thực.
- [ ] GitHub compare/diff URL nếu tiếp tục dự án có sẵn.

## Khuyến khích

- [ ] URL sản phẩm đang chạy để giám khảo tự thử.
- [ ] README có setup, kiến trúc, giới hạn và cách tái hiện demo.
- [ ] Bằng chứng sử dụng thật, thanh toán USDC thật trên testnet hoặc mainnet phù hợp.
- [ ] Mô tả cụ thể Circle/Arc primitives đã dùng.

## Thông tin form cần chuẩn bị

Email, tên dự án, GitHub/Discord/Telegram handles, số lượng và tên thành viên, lịch sử dự án (nếu có), vấn đề, mô tả kỹ thuật, traction, URL source, diff, live URL và video URL.

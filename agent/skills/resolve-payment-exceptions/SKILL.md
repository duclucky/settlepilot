# Resolve payment exceptions

1. Identify the exact missing authoritative fact for one obligation version.
2. Request one concrete answer from the project owner.
3. Do not treat free-form contractor claims as acceptance or spending authority.
4. Hold the payment until the version-bound request is resolved.
5. Re-evaluate current state after resolution; never reuse a stale decision.
